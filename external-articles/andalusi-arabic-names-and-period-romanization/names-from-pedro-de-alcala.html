Names from Pedro de Alcalá

Pedro de Alcalá’s 1505 works Arte para ligera mente saber la lengua araviga and Vocabulista aravigo en lengua castellana contain a number of names and name elements. Given names are listed with modern Spanish and Arabic equivalents as applicable, and bynames are listed with an English translation. All tables include citations for each name in Alcalá and list sources which document actual use of the name in period. An asterisk denotes a name element whose spelling I’ve hypothesized as opposed to finding directly.

Given Names

If a name is described in Alcalá as nonbre (name), nonbre de varon (male name), or nonbre de hembra/nonbre de muger (female name), that means the header form was a contemporary Spanish name. The devotional names beginning with a͑abd are marked with an asterisk because I constructed them from the component words rather than by finding them directly.

Probably my favorite names from this list are Juguăyguan and Juguăyguana, which are Arabic diminutives of the Spanish Juan and Juana, equivalent to the Spanish Juanico and Juanica.
